# PWA Receipt Scanner with QR & OCR

Прогрессивное веб-приложение (PWA) для мобильных устройств и ПК, реализующее сканер кассовых чеков с локальным хранением данных.

## Технологический стек
*   **MediaDevices API**: Доступ к камере устройства и захват кадра (`navigator.mediaDevices.getUserMedia`).
*   **BarcodeDetector API**: Встроенное в браузер аппаратное сканирование QR-кодов.
*   **Tesseract.js**: Оптическое распознавание символов (OCR) для извлечения текстовых данных из чека.
*   **IndexedDB**: Локальная база данных прямо в браузере для работы без внешнего сервера.
*   **Service Worker**: Обеспечивает полноценный Offline-режим работы приложения.

## Как запустить приложение локально

Поскольку технологии PWA и MediaDevices требуют безопасного контекста (HTTPS или localhost), проект нельзя запустить двойным кликом по `index.html`. Используйте любой локальный веб-сервер.

### Способ 1: С помощью NodeJS (рекомендуемый)
Установите и запустите простой статический сервер:
```bash
npm install -g http-server
http-server .
```
После запуска откройте в браузере адрес `http://localhost:8081`.

### Способ 2: Через расширения IDE
Если вы используете VS Code, установите расширение **Live Server** и нажмите кнопку **"Go Live"** в правом нижнем углу.

## Примеры использования и ключи интерфейса
1.  Откройте приложение и нажмите кнопку **"Включить камеру"**. Разрешите доступ к веб-камере в браузере.
2.  Наведите камеру на QR-код чека и нажмите **"Сделать фото и распознать"**. Программа мгновенно перехватит QR-данные и занесет их в базу.
3.  Если на чеке нет QR-кода, наведите камеру прямо на текст чека и сделайте фото. Приложение автоматически переключится в режим OCR, распознает текст построчно и сохранит его.
4.  Все записи отображаются в нижнем блоке «Сохраненные чеки» с указанием даты и типа сканирования.
